# Privacy Policy --- IMG to PDF

**Effective Date:** August 17, 2026

## 1. Overview

IMG to PDF is a Windows desktop application designed to convert image
files and clipboard screenshots into PDF documents.

We respect your privacy. IMG to PDF is designed to perform its core
conversion functionality locally on your Windows device and does not
require you to create an account or upload your images to a server.

## 2. Information We Access

IMG to PDF may access the following information when you explicitly use
the application's features:

-   Image files that you select or drag and drop into the application,
    including JPG, JPEG, PNG, and WebP files.
-   Image data placed on the Windows clipboard when you use the paste or
    screenshot-to-PDF feature.
-   The output folder and filename that you select for the generated
    PDF.
-   Application settings necessary to remember your preferences, such as
    the selected output location and conversion options.

IMG to PDF does not intentionally collect sensitive personal
information.

## 3. How Your Images Are Processed

Images are processed locally on your Windows device for the purpose of
creating PDF files.

Your image files, screenshots, and clipboard image data are not
intentionally uploaded to or transmitted to our servers for conversion.

The application does not require a cloud account or online conversion
service for its core image-to-PDF functionality.

## 4. Clipboard Data

If you use the clipboard or screenshot-to-PDF feature, IMG to PDF
accesses image data currently available through the Windows clipboard.

Clipboard image data is used only to perform the requested PDF
conversion.

IMG to PDF does not intentionally transmit clipboard image data to
external servers.

If temporary storage is required during conversion, temporary data is
used only as necessary to complete the operation and is cleaned up when
no longer required, subject to normal Windows operating-system behavior.

## 5. Generated PDF Files

Generated PDF files are saved to the location selected by you.

IMG to PDF does not intentionally upload generated PDFs to a remote
server.

The application does not automatically distribute or publish your
generated PDF files.

## 6. Data Sharing

IMG to PDF does not intentionally sell, rent, or share your image
content, clipboard screenshots, or generated PDF documents with third
parties.

The application does not require advertising networks or third-party
analytics services for its core functionality.

## 7. Account Information

IMG to PDF does not require users to create an account to use its core
conversion features.

The application does not intentionally collect usernames, passwords,
email addresses, phone numbers, or other account information as part of
normal conversion operations.

## 8. Internet Connectivity

The core image-to-PDF conversion functionality is designed to work
offline.

Internet connectivity is not required to select images, process
supported images locally, or create PDF files.

If a future version introduces an online feature, this Privacy Policy
will be updated before that feature is introduced where applicable.

## 9. Temporary Files

The application may create temporary files or temporary in-memory data
when required to process images and generate PDFs.

Temporary processing data is intended to be deleted when it is no longer
required.

Users should understand that Windows and the underlying storage system
may retain data temporarily according to normal operating-system
behavior.

## 10. Application Settings

IMG to PDF may store application preferences locally on the user's
device, such as:

-   Default output folder.
-   PDF page-size preference.
-   Image scaling preference.
-   Image quality or compression preference.
-   Background preference for transparent images.
-   Other conversion settings.

These settings are used to provide the application's functionality and
improve the user experience.

## 11. Diagnostics and Error Reporting

IMG to PDF is designed to avoid collecting the contents of user images,
screenshots, or generated PDFs as part of normal diagnostics.

If diagnostic logging is implemented in the application, it should avoid
recording document contents, image pixels, clipboard contents,
passwords, or other sensitive information.

## 12. Children's Privacy

IMG to PDF is a general-purpose Windows utility and does not
intentionally collect personal information from children.

Because the core application does not require an account or online
service, it does not intentionally create a profile of its users.

## 13. Third-Party Libraries

IMG to PDF may use third-party open-source libraries to provide image
decoding, PDF generation, Windows integration, or other technical
functionality.

Such libraries are used locally within the application where applicable.
Their respective licenses and notices may be provided with the
application.

## 14. Security

We take reasonable measures to design IMG to PDF so that user files are
processed locally and unnecessary transmission of user content is
avoided.

Users should continue to maintain appropriate security practices on
their Windows devices, including keeping Windows and the application
updated.

## 15. Changes to This Privacy Policy

This Privacy Policy may be updated when the application's functionality,
data practices, or applicable legal requirements change.

The updated version will include a revised effective date.

## 16. Contact

For privacy-related questions or concerns regarding IMG to PDF, please
use the support contact information provided on the application's
Microsoft Store listing.
